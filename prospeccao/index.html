    Chave do Google

    É ela que permite buscar empresas no Google Maps pelo caminho oficial.

    Como criar a chave (passo a passo)
    1. Abra console.cloud.google.com e entre com sua conta Google.
    2. No topo, toque em Selecionar projeto → Novo projeto. Dê o nome “Prospecção” e crie.
    3. Abra o menu ☰ → APIs e serviços → Biblioteca, procure Places API (New) e toque em Ativar.
    4. O Google vai pedir para ativar o faturamento (cartão). É obrigatório, mas há uma cota grátis por mês.
    5. Menu ☰ → APIs e serviços → Credenciais → Criar credenciais → Chave de API.
    6. Toque na chave criada → em Restrições de API, marque só Places API (New) → Salvar.
    7. Copie a chave (começa com “AIza”) e cole no campo acima.
    8. Recomendado: em APIs e serviços → Places API (New) → Cotas, limite as buscas por dia (ex.: 30). Assim você nunca passa da cota grátis.
